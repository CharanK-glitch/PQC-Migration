ℹ️ How It Works

1. Enter a GitHub URL above and press Start Scan.

2. The server clones the repo and scans every file for quantum-vulnerable crypto patterns.

3. Findings are saved as cbom.json and readiness_score.json.

4. The dashboard auto-refreshes — switch to Overview to see results.

5. Review completed scans and their scores in Recent Scans.
